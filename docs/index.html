吃什麼決策小幫手

寫下心情、預算或隨便想到的，店員（LLM）幫你開三張候選，再替你拍板。

最近的決定（來自資料庫）

    做了什麼

    輸入當下的心情或預算，後端呼叫 LLM，回傳經過 Pydantic 驗證的結構化結果（心情分析、3 個候選、一句話決策）。點「說服我」會用串流即時顯示店員的推薦詞。每次決定都寫進 PostgreSQL。

    展示層 webNginx：提供這個頁面，並把 /api/* 轉給應用層
    應用層 apiFastAPI：/api/decide、/api/persuade、/api/history
    資料層 dbPostgreSQL：decisions 表，放在 internal 網路

    用到的第 6 週能力：結構化輸出（beta.chat.completions.parse＋Literal 價位）與串流。以環境變數切換 Gemini／OpenAI／本地 Ollama，程式不用改。

    怎麼執行

    git clone https://github.com/<wade950608>/food-recommender-agent.git
cd food-recommender-agent
Copy-Item .env.example .env      # 填入 GEMINI_API_KEY 與資料庫密碼
docker compose up -d --build
start http://localhost:8080      # 即時互動頁

    只想用命令列

    uv sync
uv run python -m agent.cli "下雨天想吃辣，預算 300"

    改用本地模型

    # .env：LLM_PROFILE=local、LLM_BASE_URL=http://ollama:11434/v1
docker compose --profile local up -d --build
docker compose exec ollama ollama pull qwen2.5:1.5b

    在 GitHub Pages 上開這頁時，若本機已啟動 docker compose，頁面會自動連到 localhost:8080；否則進入「離線示範」。
